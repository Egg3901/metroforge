# MetroForge

A single-player 2D public transit network builder. Design and manage a transit system in a procedurally generated city that grows in response to your network. Place stations, lay track, configure routes, and balance the budget.

**Inspirations:** Mini Metro, OpenTTD, Cities Skylines, NIMBY Rails, Sid Meier's Railroads.

**Stack:** TBD by Fable — Canvas + React + Vite recommended.
