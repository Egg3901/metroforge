Installing

The builds are not code signed yet, so your system may ask before it runs a new app from a small studio. Here is exactly what to expect and how to clear it.

Windows

Run the installer. If SmartScreen says the publisher is unrecognized, choose More info, then Run anyway. The warning shows up because the build is not signed yet, not because anything is wrong with it.

macOS

Open the disk image and drag MetroForge to Applications. The first time you launch it, right click the app and choose Open, then confirm. That tells Gatekeeper you trust it.

Linux

Unpack the tarball anywhere and run the metroforge binary. If your file manager has not marked it executable, run chmod +x metroforge once.

Why MetroForge

Real city data

Maps are built from real street grids and parcels, not procedural noise. Recognize your own downtown.

Transit that actually simulates

Commuters route through your network on real travel-time math. Bad service loses riders to the road, every time.

Runs on a potato

No ray tracing, no 40 GB install. Cel shaded and lean enough to run on a five year old laptop.
